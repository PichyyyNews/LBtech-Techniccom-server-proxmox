# บทที่ 4: การแก้ไขไฟล์ Configuration (database.php และ app.php) ⚙️📝

ในบทนี้ นักศึกษาจะได้เรียนรู้วิธีการแก้ไขโค้ดตั้งค่าระบบ เพื่อให้เว็บไซต์สามารถเชื่อมต่อกับฐานข้อมูลบนเซิร์ฟเวอร์จริงได้ และให้ระบบลิงก์ไฟล์ CSS, JS, รูปภาพ ทำงานได้อย่างถูกต้องตรงตาม URL ประจำตัวของตนเอง

---

## 4.1 ทำไมต้องแก้ไฟล์ Config?

| ไฟล์ | ค่าเดิมใน XAMPP (Local) | ค่าที่ต้องเปลี่ยนบน CloudPanel (Server) | เหตุผล |
| :--- | :--- | :--- | :--- |
| **`config/database.php`** | `DB_NAME = 'ecom_store'`<br>`DB_USER = 'root'`<br>`DB_PASS = ''` | `DB_NAME = 'db_<รหัสนักศึกษา>'`<br>`DB_USER = 'u_<รหัสนักศึกษา>'`<br>`DB_PASS = '<รหัสผ่านที่ตั้งไว้>'` | เซิร์ฟเวอร์จริงไม่อนุญาตให้ใช้ `root` ที่ไม่มีรหัสผ่านเพื่อความปลอดภัย |
| **`config/app.php`** | `BASE_URL = '/e-com'` | `BASE_URL = '/<รหัสนักศึกษา>'` | บนเซิร์ฟเวอร์ หน้าเว็บของนักศึกษาจะอยู่ที่ `/69319090021` หากไม่แก้ ลิงก์ CSS/JS และรูปภาพจะพัง (404 Not Found) |

---

## 4.2 วิธีเปิดแก้ไขไฟล์ผ่าน CloudPanel File Manager

1. ในหน้า **Files** บน CloudPanel นำทางไปยังโฟลเดอร์:  
   `... / htdocs / lab.pichyy.qzz.io / <รหัสนักศึกษา> / config /`
2. คลิกขวาที่ไฟล์ที่ต้องการแก้ไข แล้วเลือก **Edit** (หรือดับเบิลคลิกที่ไฟล์)
3. ระบบจะเปิดหน้าต่าง Code Editor ขึ้นมา สามารถพิมพ์แก้ไขโค้ดได้ทันที
4. เมื่อแก้ไขเสร็จแล้ว ให้กดปุ่ม **Save** (บันทึก) สีฟ้าที่มุมขวาบน

---

## 4.3 แก้ไขไฟล์ที่ 1: `config/database.php`

เปิดไฟล์ `config/database.php` แล้วแก้ไขบรรทัดที่ 4 - 8 ดังตัวอย่าง:

### 🔴 โค้ดเดิม (Before - บนเครื่อง XAMPP):
```php
<?php
// config/database.php

define('DB_HOST', 'localhost');
define('DB_NAME', 'ecom_store');
define('DB_USER', 'root');
define('DB_PASS', '');
define('DB_CHARSET', 'utf8mb4');
```

### 🟢 โค้ดใหม่ (After - บน CloudPanel Server):
*(สมมุติว่ารหัสนักศึกษาคือ `69319090021` และรหัสผ่านฐานข้อมูลคือ `Pass@69319090021!`)*

```php
<?php
// config/database.php

define('DB_HOST', 'localhost');
define('DB_NAME', 'db_69319090021');         // <-- ใส่ชื่อ Database ที่สร้างในบทที่ 2
define('DB_USER', 'u_69319090021');          // <-- ใส่ชื่อ User ที่สร้างในบทที่ 2
define('DB_PASS', 'Pass@69319090021!');       // <-- ใส่ Password ที่ตั้งไว้ในบทที่ 2
define('DB_CHARSET', 'utf8mb4');
```

> [!CAUTION]  
> ห้ามมีเว้นวรรค (Spacebar) เกินในเครื่องหมายคำพูดเดี่ยว `'...'` และอย่าลืมใส่เครื่องหมาย `;` ท้ายบรรทัดเสมอ

---

## 4.4 แก้ไขไฟล์ที่ 2: `config/app.php`

เปิดไฟล์ `config/app.php` แล้วแก้ไขบรรทัดที่ 10 (ค่า `BASE_URL`):

### 🔴 โค้ดเดิม (Before - บนเครื่อง XAMPP):
```php
define('APP_NAME', 'CLOTHIFY Store');
define('APP_TAGLINE', 'ร้านเสื้อผ้าแฟชั่นออนไลน์ คุณภาพพรีเมียม สไตล์มินิมอล');
define('BASE_URL', '/e-com');
```

### 🟢 โค้ดใหม่ (After - บน CloudPanel Server):
*(สมมุติว่ารหัสนักศึกษาคือ `69319090021`)*

```php
define('APP_NAME', 'CLOTHIFY Store');
define('APP_TAGLINE', 'ร้านเสื้อผ้าแฟชั่นออนไลน์ คุณภาพพรีเมียม สไตล์มินิมอล');
define('BASE_URL', '/69319090021');          // <-- เปลี่ยนเป็น /ตามด้วยรหัสนักศึกษา
```

> [!IMPORTANT]  
> สังเกตว่า `BASE_URL` ต้องมีเครื่องหมาย Slash นำหน้า (`/`) และ **ไม่มี** Slash ปิดท้าย เช่น `'/69319090021'` เท่านั้น

---

## 4.5 ตรวจสอบโฟลเดอร์สำหรับอัปโหลดไฟล์รูปภาพ (`uploads/`)

เพื่อให้ระบบเพิ่มสินค้าและแนบสลิปโอนเงินสามารถบันทึกไฟล์ภาพลงเซิร์ฟเวอร์ได้:
1. ดูใน File Manager ว่ามีโฟลเดอร์ `uploads/` และ `uploads/products/` หรือไม่
2. หากยังไม่มี ให้คลิกปุ่ม **New Folder** เพื่อสร้างโฟลเดอร์:
   * สร้าง `uploads`
   * เข้าไปใน `uploads` แล้วสร้าง `products`
