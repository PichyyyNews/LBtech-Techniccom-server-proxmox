# บทที่ 2: การสร้าง Database & User บน CloudPanel และ Import ข้อมูล 🗄️⚡

ในบทนี้ นักศึกษาจะได้เรียนรู้วิธีการล็อกอินเข้าสู่ระบบจัดการ **CloudPanel** ของเซิร์ฟเวอร์ สร้างฐานข้อมูล MySQL และ Database User ประจำตัว รวมถึงการนำไฟล์ `.sql` ที่เตรียมไว้ในบทที่ 1 นำเข้า (Import) เข้าสู่ฐานข้อมูลจริงผ่าน **phpMyAdmin**

---

## 2.1 เข้าสู่ระบบ CloudPanel Control Panel

1. เปิดเว็บเบราว์เซอร์ (Google Chrome, Microsoft Edge, หรือ Firefox)
2. เข้าสู่ URL แผงควบคุมเซิร์ฟเวอร์: **[https://techniccom-cp.pichyy.qzz.io](https://techniccom-cp.pichyy.qzz.io)**
3. กรอกข้อมูลล็อกอินของนักศึกษา:
   * **User Name:** `std` ตามด้วยรหัสนักศึกษา (เช่น `std69319090021`)
   * **Password:** `Std@` ตามด้วยรหัสนักศึกษา (เช่น `Std@69319090021`)
4. คลิกปุ่ม **Log In**

> [!NOTE]  
> หากพบหน้าจอแจ้งเตือนความปลอดภัย SSL ให้คลิก **Advanced (ขั้นสูง)** แล้วเลือก **Proceed to ... (ดำเนินการต่อ)**

## 2.2 สร้าง Database และ Database User ใหม่

เมื่อล็อกอินเข้ามาแล้ว จะพบหน้าต่างจัดการเว็บไซต์ `lab.pichyy.qzz.io` ให้ดำเนินการสร้างฐานข้อมูลดังนี้:

```mermaid
flowchart LR
    A["เข้าเมนู Databases"] --> B["คลิก Add Database"]
    B --> C["กรอกชื่อ Database<br>db_<รหัสนักศึกษา>"]
    C --> D["กรอกชื่อ User<br>u_<รหัสนักศึกษา>"]
    D --> E["กำหนดรหัสผ่าน<br>(คัดลอกเก็บไว้!)"]
    E --> F["กดปุ่ม Add Database"]
```

### ขั้นตอนการสร้าง:
1. คลิกที่เมนู **Databases** บนแถบเมนูด้านบน
2. คลิกปุ่มสีฟ้า **+ Add Database**
3. กรอกข้อมูลในฟอร์มดังนี้:
   * **Database Name:** ตั้งชื่อขึ้นต้นด้วย `db_` ตามด้วยรหัสนักศึกษา เช่น `db_69319090021`
   * **Database User Name:** ตั้งชื่อขึ้นต้นด้วย `u_` ตามด้วยรหัสนักศึกษา เช่น `u_69319090021`
   * **Database User Password:** กำหนดรหัสผ่านฐานข้อมูลที่ปลอดภัย เช่น `Pass@69319090021!` (หรือคลิกไอคอนลูกศรเพื่อสุ่มรหัสผ่าน)
4. > [!IMPORTANT]  
   > **ข้อสำคัญมาก:** ให้จดบันทึก **Database Name**, **Database User**, และ **Password** นี้ไว้ใน Notepad ทันที เพราะจะต้องนำไปกรอกในไฟล์ `config/database.php` ในบทที่ 4
5. คลิกปุ่ม **Add Database** เพื่อบันทึก

## 2.3 เปิด phpMyAdmin และ Import ไฟล์ `.sql`

เมื่อสร้างฐานข้อมูลสำเร็จ รายการฐานข้อมูลจะปรากฏขึ้นในตาราง:

1. ดูที่แถวของฐานข้อมูลที่เพิ่งสร้าง (เช่น `db_69319090021`)
2. คลิกที่ปุ่ม **Manage Database** (หรือไอคอน phpMyAdmin)
3. ระบบจะเปิดหน้าต่าง **phpMyAdmin** ของ CloudPanel ขึ้นมา
4. ที่แถบเมนูด้านซ้าย ให้คลิกเลือกชื่อฐานข้อมูลของตนเอง (เช่น `db_69319090021`)
5. คลิกที่แท็บ **Import** (นำเข้า) ด้านบน
6. ในหัวข้อ **File to import:** คลิกปุ่ม **Choose File** (หรือ Browse) แล้วเลือกไฟล์ `database.sql` (หรือ `ecom_store.sql`) ที่บันทึกไว้ในบทที่ 1
7. เลื่อนลงมาด้านล่างสุด แล้วกดปุ่ม **Import** (หรือ Go)
8. รอสักครู่ เมื่อสำเร็จจะมีแถบแจ้งเตือนสีเขียว:  
   *`Import has been successfully finished, xx queries executed.`*

---

## 2.4 ตรวจสอบความสมบูรณ์ของตารางข้อมูล

ให้สังเกตที่แถบเมนูด้านซ้ายใน phpMyAdmin ควรมีตารางข้อมูลครบถ้วน ดังนี้:
- ✅ `categories` (ตารางหมวดหมู่สินค้า)
- ✅ `products` (ตารางรายการสินค้า)
- ✅ `users` (ตารางสมาชิกและผู้ดูแลระบบ)
- ✅ `orders` (ตารางรายการสั่งซื้อ)
- ✅ `order_items` (ตารางรายการสินค้าในคำสั่งซื้อ)
- ✅ `payments` (ตารางการแจ้งชำระเงินและสลิป)

> [!TIP]  
> หากต้องการตรวจสอบข้อมูลผู้ดูแลระบบ (Admin) ให้ลองคลิกที่ตาราง `users` เพื่อดู Username และ Password สำหรับเข้าสู่ระบบหลังบ้าน
